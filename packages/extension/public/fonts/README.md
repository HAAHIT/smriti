# Vendored fonts

These files ship inside the extension so Smriti makes **no** network request for
typography. Previously the sidebar injected a `<link>` to
`fonts.googleapis.com` into every host page and the options page loaded the same
stylesheet — an outbound request to Google on every claude.ai / chatgpt.com /
gemini.google.com visit, from a product whose store listing and privacy policy
assert that nothing leaves the device.

The `@font-face` rules that reference these files are generated by
[`lib/fonts.ts`](../../lib/fonts.ts), which is the single source of truth for
both the sidebar content script and the options page.

## What's here

All three families are **variable** fonts, so one file per Unicode subset covers
every weight the UI uses. Only `latin` and `latin-ext` are vendored — the UI is
English-only today. (If Phase 2's multilingual work needs more coverage, add the
subsets here and the matching entries in `lib/fonts.ts`.)

| File | Family | Axes vendored |
|---|---|---|
| `inter-latin.woff2`, `inter-latin-ext.woff2` | Inter | `wght 400..700` |
| `source-serif-4-latin.woff2`, `source-serif-4-latin-ext.woff2` | Source Serif 4 | `opsz 8..60`, `wght 400..700` |
| `jetbrains-mono-latin.woff2`, `jetbrains-mono-latin-ext.woff2` | JetBrains Mono | `wght 400..500` |

To refresh, request the variable ranges from the `css2` endpoint with a modern
browser User-Agent and take the `latin` / `latin-ext` `woff2` URLs:

```
https://fonts.googleapis.com/css2?family=Inter:wght@400..700&display=swap
https://fonts.googleapis.com/css2?family=Source+Serif+4:opsz,wght@8..60,400..700&display=swap
https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400..500&display=swap
```

Also update the `unicode-range` constants in `lib/fonts.ts` if upstream changes
them.
