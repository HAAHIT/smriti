Smriti Privacy Policy

Last updated: 2026-05-24

Smriti is built local-first. Short version: your conversations never leave your browser.

What Smriti collects

Smriti archives the AI conversations you have on claude.ai, chatgpt.com, and gemini.google.com. For each conversation it stores: message text, conversation metadata (title, platform, URL, timestamps), and a locally-computed embedding vector for semantic search.

Where your data is stored

All data is kept in a SQLite database inside your browser's Origin Private File System (OPFS) — sandboxed to this extension, invisible to websites, never readable by Smriti's developers or any third party. There is no local helper program, no companion app, no external database.

What Smriti does NOT collect

  • No analytics or telemetry
  • No crash reports
  • No accounts
  • No browser history, bookmarks, cookies, passwords, or activity outside the three AI hosts

Network requests

  1. One-time model download — the all-MiniLM-L6-v2 ONNX model (~25 MB) from Hugging Face's CDN on first use. Cached permanently. Contains no user data.
  2. Backfill fetch — when you click "Import history", Smriti uses your existing browser session to fetch past conversations from claude.ai or chatgpt.com directly. Smriti never sees your password or auth tokens.

No conversation content, message text, or embeddings are ever transmitted to any server.

Permissions

  • storage — UI preferences only (theme, pause toggles). No conversation data.
  • offscreen — persistent hidden page that owns the SQLite database and embedding pipeline. All data stays inside Chrome.
  • scripting — injects the sidebar into AI chat tabs.
  • Host permissions for claude.ai, chatgpt.com, gemini.google.com — to run capture scripts and the sidebar on those three surfaces only.

Your controls

From Settings you can pause capture per host, or wipe the entire archive. Uninstalling the extension causes Chrome to delete its OPFS storage automatically.
